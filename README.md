# **Customer Segmentation using Clustering :-**

A beginner-friendly Machine Learning project that groups mall customers using K-Means Clustering.

📌 **Project Overview :-**

This project groups customers based on :
* Age
* Annual Income
* Spending Score to identify different customer segments

🛠️ **Technologies Used :-**

* Python
* Pandas
* Matplotlib
* Scikit-learn
* K-Means Clustering

🔍 **Steps :-**

1. Load the customer dataset.
2. Select important features.
3. Apply K-Means clustering.
4. Create customer groups.
5. Visualize the clusters.
6. Display the results.

📊 **Output :-**

* Customer groups
* Cluster visualization

🎯 **Learning Outcome :-**

This project helped me to learn the basics of K-Means clustering, customer segmentation, and data visualization.
